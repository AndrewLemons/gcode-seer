# Research notes

Reviewed September 22, 2026. Upstream firmware and slicer behavior can change. These links document the basis for the implementation, not a compatibility guarantee for future releases.

| Primary source                                                                                                                                                                                                                                                                      | Design consequence                                                                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Marlin G0/G1](https://marlinfw.org/docs/gcode/G000-G001.html)                                                                                                                                                                                                                      | Feedrate is modal and expressed per minute. Requested motion differs from the acceleration-limited path executed by firmware. The default model treats G0 like G1; non-Cartesian rapid motion needs another model.       |
| [Marlin M82](https://marlinfw.org/docs/gcode/M082.html)                                                                                                                                                                                                                             | G90/G91 clear the E positioning override in the Marlin preset.                                                                                                                                                           |
| [Marlin G92](https://marlinfw.org/docs/gcode/G092.html)                                                                                                                                                                                                                             | Position rebasing must preserve the physical coordinate.                                                                                                                                                                 |
| [Marlin G2/G3](https://marlinfw.org/docs/gcode/G002-G003.html)                                                                                                                                                                                                                      | I/J offsets, R form, full circles and Z interpolation need explicit arc handling. The library rejects inconsistent radii instead of relying on firmware-specific correction.                                             |
| [Marlin M200](https://marlinfw.org/docs/gcode/M200.html)                                                                                                                                                                                                                            | Volumetric E must be converted using filament cross-sectional area.                                                                                                                                                      |
| [Marlin planner source](https://github.com/MarlinFirmware/Marlin/blob/bugfix-2.1.x/Marlin/src/module/planner.cpp)                                                                                                                                                                   | Pure extrusion motion uses the scaled filament distance; XYZ motion uses the spatial path. Planner clamping remains separate from requested-speed analysis.                                                              |
| [Klipper command reference](https://www.klipper3d.org/G-Codes.html) and [gcode_move.py](https://github.com/Klipper3d/klipper/blob/master/klippy/extras/gcode_move.py)                                                                                                               | M83 is a relative override, M82 follows global positioning, and G20 is rejected. Macro expansion, offsets and carriage duplication require configured behavior.                                                          |
| [Bambu Studio GCodeProcessor](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/GCode/GCodeProcessor.cpp)                                                                                                                                                           | Bambu's reference processor combines global relative positioning with the E-relative override. It also handles physical heater mapping and S/P/U variants of M400.                                                       |
| [Bambu X1 Carbon nozzle profile](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20X1%20Carbon%200.4%20nozzle.json)                                                                                                                  | The front-left exclusion is encoded as `0x0`, `18x0`, `18x28`, `0x28`. The built-in profile treats it as a deposition exclusion.                                                                                         |
| [Bambu common machine profile](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/fdm_bbl_3dp_001_common.json) and [common FDM profile](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/fdm_machine_common.json) | The reviewed X1 chain gives a 256 × 256 mm area and an inherited 250 mm printable height. These slicer limits are distinct from the physical service-travel envelope. Imported exclusion helpers expect resolved values. |
| [Bambu H2D nozzle profile](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20H2D%200.4%20nozzle.json)                                                                                                                                | Material assignments, physical extruders, nozzle variants and printable geometry are distinct concepts. A list of T numbers is insufficient to model every multi-nozzle machine.                                         |

No upstream firmware or slicer implementation is copied into the library. Tests use small, original programs with explicit expectations. This release does not yet include a corpus of physical printer runs or claim validation against closed Bambu firmware.
